# Nuvellic — Turn Days Into a Life

**Live Web App:** [https://nuvellic.netlify.app](https://nuvellic.netlify.app)

**Nuvellic** is a minimalist habit tracker and private daily reflection journal built around behavioral science principles. Designed as a calm workspace for daily planning and self-reflection, it helps you build consistent routines without visual clutter, aggressive notifications, or high-pressure streaks.

---

## Key Features

* **Visual Habit Tracking:** Build daily consistency using a clean, low-friction grid rather than gamified streak anxiety.
* **Private Daily Reflection Journal:** Write distraction-free daily entries and monthly notes in a quiet, personal space.
* **Behavioral Science First:** Structured to reduce cognitive overload and keep your focus on intentional daily habits.
* **Zero Social Noise:** No public feeds, leaderboards, or distractions—just your habits and thoughts.
* **Cross-Platform Sync:** Access your routines and journal entries seamlessly across devices.
